Stochastic trend analysis

Berveridge-Nelson Decomposition

The Beveridge-Nelson decomposition[1] divides a time series into two stochastic components, given that the time series is non-stationary (has a unit root) or in other terms that the series can be modeled as an ARIMA(p, 1, q) process with drift.

Unlike in other models the decomposition of time series $y$ in terms of trend $\tau$ and cycle $c$ components is defined as:

\[ y_t = \tau_t - c_t\]

This package offers two ways of computing the decomposition, one by Miller[2] for autoregressive models and one by Newbold[3] for ARMA models. For the latter it is also possible to calculate the decomposition with already estimated parameters of an ARIMA(p, 1, q) model, otherwise the function armaNR (see ARMA(p, q)) is used.

TrendDecomposition.beveridgeNelson — Function
beveridgeNelson(X :: Vector, p :: Int; method::Symbol=:Newbold, estimator::Symbol=:OLS)

Computes the Beverdige-Nelson decomposition of a non-stationary time series X using an autoregressive model for estimation with p-lags. As estimators :OLS, :burg, :yuleWalker can be used.

Either uses Newbold's (1990) or Miller's (1987) method of computation.

Returns a (Nx1) vector of the trend component.

beveridgeNelson(X :: Vector, p :: Int, q :: Int)

Computes the Beverdige-Nelson decomposition of a non-stationary time series X using an ARMA(p, q) model.

Uses Newbold's (1990) method of computation.

Returns a (Nx1) vector of the trend component.

source
beveridgeNelson(X :: Vector, ϕ :: Vector, θ :: Vector)

Computes the Beverdige-Nelson decomposition of a non-stationary time series X using an ARMA(p, q) model of ΔX given the AR parameter ϕ and MA parameter θ.

Uses Newbold's (1990) method of computation.

Returns a (Nx1) vector of the trend component.
